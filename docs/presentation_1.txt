lineage frontend 

Flowscope Enterprise Edition представляет собой платформу для построения графовых структур.

Ключевой особенностью платформы является возможность анализа SQL-запросов.

Платформа состоит из frontend и backend модулей.

Frontend включает в себя подсистему парсинга SQL непосредственно в браузере.

Подсистема парсинга поддерживает несколько современных диалектов, 
таких как bigquery, postgres, snowflake и прочие.
Также имеется возможность работы с шаблонными запросами, например, DBT/Jinja

Подсистема связи с сервером позволяет выполнять, обрабатывать и визуализировать информацию серверной стороны.
Например, парсинг SQL запросов и построение lineage на сервере, получение данных и meta-данных.

Таким образом платформа соединяет в себе важные для анализа аспекты:
- данные
- технические meta-данные
- lineage
- governance информацию (классификация, владение, качесво данных и пр.)

Визуальная часть содержит 
- проекты, с удобной навигацией по SQL-файлам 
- редакторы SQL-запросов
- внутренняя файловая система (в кэше браузера)
- связь с файловой системой на компьютере пользователя
- область работы с lineage в виде графа, иерархии или матрицы
- область работы с данными, с возможностью группировки, разделения, построения графиков и экспорта

Работа с текстом SQL запроса предполагает двусторонюю связь с графом (lineage)
- запуск SQL-запросов с получением данных
- запуск отдельных CTE
- возможность быстрого перехода к любому объекту графа (таблицы, CTE, колонки)
- возможность получения технической информации об объектах базы данных
- форматирование SQL в соответствии с требованиями организации

Работа с графом (lineage) также предполагает 
- двусторонюю связь с текстом SQL запроса 
- фильтрацию узлов графа по таблицам, CTE, схемам, путям прохождения потоков данных
- анализ lineage в табличном формате и в формате колонок
- отслеживание и анализ потоков данных
- получение технической и governance информации по узлам и колонкам
- возможность выполнять SQL-запросы и получать данные по отдельным табличным узлам
- share Project
- экспорт графа в различные форматы: Excel, Json, CSV, PNG, Mermaid, HTML Report
- экспорт графа в виде DDL/DML/SQL


Все представленные выше возможности делают работу по анализу данных максимально удобной.
